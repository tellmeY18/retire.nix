# OpenClaw Gateway on chopper

[OpenClaw](https://github.com/openclaw/nix-openclaw) is an AI assistant
gateway. It runs as a NixOS systemd service on `chopper` and is accessible
over the local network (LAN) via WebSocket.

## Quick reference

| Item | Value |
|---|---|
| LAN endpoint | `ws://chopper.lan:18789` or `ws://<chopper-ip>:18789` |
| Config file | `/etc/openclaw/openclaw.json` (generated by Nix) |
| State directory | `/var/lib/openclaw/` |
| Logs | `/var/lib/openclaw/logs/gateway.log` |
| systemd unit | `openclaw-gateway.service` |
| OpenClaw config sources | `hosts/chopper/parts/services.nix` (Nix), sops secrets via `hosts/chopper/sops.nix` |
| Channels | Signal (official `@openclaw/signal` runtime plugin) |

______________________________________________________________________

## Connecting

Any WebSocket-capable client can connect to the gateway:

```sh
# From another machine on the same LAN:
openclaw gateway connect --url ws://192.168.1.100:18789 --token <token>

# Over Tailscale:
openclaw gateway connect --url ws://100.107.213.17:18789 --token <token>
```

The gateway token is set via the `OPENCLAW_GATEWAY_TOKEN` environment
variable (see [Secrets](#secrets) below).

## Service management

```sh
# Status
systemctl status openclaw-gateway

# Logs (follow)
journalctl -u openclaw-gateway -f

# Logs (recent tail)
tail -50 /var/lib/openclaw/logs/gateway.log

# Restart
systemctl restart openclaw-gateway
```

## Configuration

The gateway is configured in
`hosts/chopper/parts/services.nix` under
`services.openclaw-gateway.config`. The full option set is generated
from the upstream OpenClaw config schema — see
`nix/generated/openclaw-config-options.nix` in the
[nix-openclaw](https://github.com/openclaw/nix-openclaw) repo.

### Adding a channel (Signal)

Signal is configured via the official `@openclaw/signal` runtime plugin, loaded
declaratively from the upstream nix-openclaw flake. The phone number is passed
as an environment variable from the sops-decrypted secret.

```nix
{ config, pkgs, openclaw-signal-plugin, ... }:

services.openclaw-gateway = {
  config = {
    plugins.load.paths = [
      "${openclaw-signal-plugin}"
    ];
    channels.signal = {
      enabled = true;
      configPath = "/var/lib/signal-cli";
      autoStart = true;
    };
  };
  servicePath = [ pkgs.signal-cli ];
};
```

The Signal phone number must be registered imperatively once (SMS verification):

```bash
ssh root@chopper
export OPENCLAW_SIGNAL_NUMBER="$(cat /run/secrets/openclaw-signal-number)"
signal-cli -u "$OPENCLAW_SIGNAL_NUMBER" register
signal-cli -u "$OPENCLAW_SIGNAL_NUMBER" verify <code-from-sms>
systemctl restart openclaw-gateway
```

### Adding an LLM provider (Anthropic)

```nix
services.openclaw-gateway = {
  config = {
    agents.defaults.model = "claude-sonnet-4-20250514";
    models.providers.anthropic = {
      apiKey = { source = "env"; provider = "default"; id = "ANTHROPIC_API_KEY"; };
    };
  };
  environment.ANTHROPIC_API_KEY = config.sops.secrets.openclaw-anthropic-key.path;
};
```

## Secrets

All secrets are managed via sops-nix — never put plaintext tokens in Nix
files.

### Adding a new secret

1. Add the sops secret declaration in `hosts/chopper/sops.nix`:

   ```nix
   sops.secrets."openclaw-signal-number" = { };
   ```

1. Encrypt the value into `secrets/chopper/secrets.yaml`:

   ```sh
   sops secrets/chopper/secrets.yaml
   ```

   Add a new key, e.g.:

   ```yaml
   openclaw-signal-number: "+15551234567"
   ```

1. Wire it in `hosts/chopper/parts/services.nix`:

   ```nix
   services.openclaw-gateway = {
     # The wrapper script reads this from sops and exports OPENCLAW_SIGNAL_NUMBER
   };
   ```

1. Deploy: `just deploy chopper`

### Current secrets

The following env vars are wired from sops-decrypted files:

| Env var | Secret key | Purpose |
|---|---|---|
| `OPENCLAW_GATEWAY_TOKEN` | `openclaw-gateway-token` | Gateway auth token for WebSocket clients |
| `ANTHROPIC_API_KEY` | `openclaw-anthropic-key` | Anthropic API key for Claude models |
| `OPENAI_API_KEY` | `openclaw-openai-key` | OpenAI API key for GPT models |
| `OPENCLAW_SIGNAL_NUMBER` | `openclaw-signal-number` | Signal phone number for the Signal channel |

## How it works

```
Client ──ws://chopper:18789──► OpenClaw Gateway ──► LLM Provider (Anthropic etc.)
                                     │
                                     └──► Bundled plugins (peekaboo, summarize, etc.)
```

- The gateway binds to `0.0.0.0:18789` (`--bind all`) so it's reachable on
  any network interface.
- The firewall allows TCP 18789 on all interfaces (not just tailscale).
- Only the `openclaw` user can read state at `/var/lib/openclaw/`.
- Config is rebuilt on every `nixos-rebuild` — never edit
  `/etc/openclaw/openclaw.json` by hand.
